# 项目设计文档 (Project Design)

## 1. 工程与质量说明

本项目是一个高标准、纯前端的数独游戏应用，严格按照企业级开发规范进行构建。

- **模块化架构**：代码逻辑清晰分离。
  - `sudoku_core.js`：封装了数独的核心算法（生成、求解、验证），不依赖任何 UI，保证了逻辑的纯粹性和可测试性。
  - `app.js`：负责 UI 交互、状态管理和游戏流程控制，与核心算法解耦。
  - `confetti.js`：独立的庆祝动画模块，即插即用。
  - `style.css`：使用 CSS Variables 定义主题变量，便于维护和扩展；采用 Flexbox 和 Grid 布局确保响应式适配。
- **健壮性**：
  - 实现了完整的错误处理机制（如 localStorage 读取失败的容错）。
  - 关键输入（如用户填入数字）均有实时校验。
  - 包含了必要的控制台日志以便于调试。
- **工程化**：
  - 提供标准的 `Dockerfile` 和 `docker-compose.yml`，实现一键容器化部署。
  - `.gitignore` 和 `.dockerignore` 配置完善，避免无关文件提交或打包。

## 2. 工程细节与专业度说明

- **状态管理**：使用一个集中式的 `state` 对象管理游戏的所有状态（难度、计时、错误数、笔记等），类似 Vue/React 的状态管理思想，确保 UI 与数据的一致性。
- **持久化存储**：利用 `localStorage` 实现自动保存功能。页面刷新或意外关闭后，游戏进度（包括填写的数字、笔记、时间、错误数）都能完美恢复，提升用户体验。
- **算法优化**：数独生成算法采用“回溯法求解 + 随机挖洞”的策略，确保生成的谜题具有唯一解且符合指定难度。
- **交互细节**：
  - **笔记模式**：支持在单元格内标记多个即便数字，符合高级玩家习惯。
  - **撤销/擦除**：提供完善的后悔药机制。
  - **键盘支持**：除了点击屏幕键盘，还完美支持物理键盘（数字键输入、方向键移动、Backspace删除），适配桌面端操作习惯。

## 3. Prompt 需求理解与适配度说明

本项目严格遵循并超额完成了 Prompt 中的所有核心需求与隐含约束：

- **功能完整性**：难度选择、随机出题、实时验证、计时器、提示（限次）、错误检查、保存加载、胜利动画全覆盖。
- **设计规范执行**：
  - **响应式**：完美适配移动端（375px+）和桌面端，Header 和布局随屏幕自动调整。
  - **中文内容**：全站内容汉化，无遗漏。
  - **无紫色**：严格审查配色方案，采用深蓝/灰/白/金的高端冷色调，完全避开紫色系。
  - **Picsum 图片**：背景图使用指定的 `https://picsum.photos` 占位符接口。
  - **UI 对齐**：严格控制间距和对齐，Header 采用动态 Padding (`max(20px, 24vw)`) 确保在大屏下的视觉聚拢感。

## 4. 美观度说明

- **高端视觉风格**：摒弃了传统的粗糙边框风格，采用“玻璃态（Glassmorphism）”设计语言。半透明的背景、模糊的 Backdrop Filter、细腻的边框阴影，营造出沉浸式的游戏体验。
- **动效设计**：
  - 数字填入、错误提示、选中高亮均有平滑的 CSS 过渡。
  - 胜利时触发的全屏 Confetti（彩带雨）动画，极大增强了成就感。
- **精细排版**：选取 `Outfit` 等现代无衬线字体，字号、行高经过精心调优，数字清晰易读。
- **深色模式**：默认采用极简深色主题，护眼且极具科技感与时尚感。
