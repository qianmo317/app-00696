# 极简・数独 (Zen Sudoku)

一个高端、大气、时尚的纯前端数独游戏。

## 1 How to Run

### 本地运行

直接用浏览器打开 `frontend-user/index.html` 即可体验。

### Docker 运行

在根目录下执行：

```bash
docker-compose up --build -d
```

访问 http://localhost:8081

## 2 Services

| Service Name  | Port | Description      |
| :------------ | :--- | :--------------- |
| frontend-user | 8081 | 数独游戏前端页面 |

## 3 测试账号

本项目为纯前端无后端应用，无需登录，也无测试账号。

## 4 题目内容

设计并开发一个功能完整、用户友好的数独游戏应用。该应用应包含以下核心功能：游戏难度选择（初级、中级、高级）、随机生成符合数独规则的谜题、实时输入验证、计时器功能、提示系统（限制使用次数）、错误检查、游戏进度保存与加载、以及胜利条件判断与庆祝动画。界面设计需简洁直观，包含9x9的数独网格，清晰的数字输入区域，必要的游戏控制按钮（重新开始、暂停、提示等），并确保在不同设备上都能提供良好的响应式体验。代码实现应采用模块化结构，确保逻辑清晰、易于维护，并包含必要的注释。html

## 项目介绍

这是一个基于 HTML, CSS, JavaScript 开发的响应式数独游戏。

### 核心功能

- **多难度选择**：初级、中级、高级
- **智能出题**：实时生成唯一解的数独谜题
- **辅助功能**：
  - 实时错误检查
  - 智能提示（有限次）
  - 笔记模式
- **游戏进度**：
  - 自动计时
  - 进度自动保存与加载
- **视觉体验**：
  - 高端极简设计
  - 响应式布局（完美适配移动端与桌面端）
  - 胜利庆祝动画

### 技术栈

- HTML5
- CSS3 (Variables, Flexbox, Grid, Animations)
- JavaScript (ES6+)
- Docker & Nginx
